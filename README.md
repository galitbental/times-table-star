# ⭐ Times Table Star

A fun, rewarding website where children practice the multiplication table.

## How to play
1. Pick a table (×1 to ×10) or 🎲 **Mix** for random questions.
2. Type the answer and press **Enter** or **Check**.
3. A correct answer gives you a ★ star and grows your 🔥 streak. Get 5 in a row for confetti and a 🏆!
4. A wrong answer? No problem: try again until you get it right.

## Run it
Open `index.html` in any modern browser. There's no build step and nothing to install.

## Design
The motion follows Emil Kowalski's design-engineering principles:
- quick custom ease-out animations
- press feedback on buttons
- hover effects only on devices with a mouse
- full `prefers-reduced-motion` support
